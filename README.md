# CSNZ-iOS

ARM64 iOS interoperability project for locally owned Counter-Strike Nexon game data.

This repository contains only open-source build/runtime glue. It does **not** contain Nexon/Valve proprietary game assets, Windows binaries, authentication components, or anti-cheat components.

Runtime baseline: FWGS/xash3d-fwgs. Proprietary assets are extracted from the user's legitimate local Steam installation and integrated locally after the public runtime build.
